# Portfolio_Nicolas

## Description
Ce projet a pour but d'être une page web sur moi qui servira de portfolio. Cela me permet également de garder dans un endroit la totalité de mes projets sur un même et site web qui sera mise à jour au fil du temps.

---
## Sections de la page

### Acceuil
Une page statique de bienvenu qui permet d'accéder au quatre autres pages. C'est une page acceuillante qui permet de regrouper le tout


### Page à propos
Une page de description sur moi même qui permet de donner certains informations et également des moyens de me contacter.


### Page Compétences
Permet de montrer les logiciels et languages de programmations que je connais et mon niveau dans chacun d'eux. Je reste malgré tout un étudiant, mais je peux me permettre de dire dans les quelles je suis plus fort ou non.


### Page Projets d'étude
Une page remplit de dossiers ou dans chaque dossier on peut y trouver un projet d'étude que j'ai réalisé. Les projets n'ont pas vraiment d'ordre et certains sont plus impressionnant que d'autres.

### Page Projets Personnelles
Une page remplit de dossiers également ou dans chaque dossier on peut y trouver un projet personnel sur le quel je travaille ou que j'ai terminé. Le but est de ses projets est d'améliorer mes compétences avec mes connaissances déjà acquises.
